I've decided to rebuild my personal website from scratch.

The idea is to have a place of my own on the internet, where I can share things that don't necessarily fit into a GitHub repository or a social media post.

## How it's built

The website is built with Astro, uses Markdown for its content and is designed to be hosted on GitHub Pages.

I want to keep it simple, maintainable and independent of unnecessary services.
